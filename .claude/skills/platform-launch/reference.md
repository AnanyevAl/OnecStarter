# Запуск 1С — полный справочник

Источник: ИТС, «Приложение 7. Параметры командной строки запуска» и «Приложение 3»,
версии 8.3.18…8.5.4. Пометка **[Ф]** — проверено на реальной машине.

## Режимы запуска

Одновременное использование нескольких режимов не допускается. Режим — первым аргументом.

```
1cv8 ENTERPRISE [<параметры>]
1cv8 DESIGNER [<команды>]
1cv8 CREATEINFOBASE <строка соединения> [/AddToList [<имя>]] [/UseTemplate <файл>]
                    [/Out <файл>] [/L<язык>] [/VL<локализация>] [/O<скорость>] [/DumpResult <файл>]
```

Для платформы 8.0 при автоподборе версии `DESIGNER` заменяется на `CONFIG`.

## Параметры подключения

| Ключ | Смысл |
| --- | --- |
| `/F <каталог>` | Каталог с файлом `1Cv8.1CD` |
| `/S <адрес>` | `<сервер>/<имя ИБ>`. Разделитель `/` работает в любой ОС, `\` — только Windows, `"server\ib"` — в любой |
| `/IBName <имя>` | Поиск базы по имени в списке. **Если баз с таким именем больше одной — запуск прекращается с ошибкой.** Кавычки в имени удваиваются: `База ""СтройТорг""` |
| `/IBConnectionString <строка>` | Строка соединения целиком. Части могут быть переопределены другими параметрами, **если те стоят в командной строке позже** |
| `/WS <url>` | Строка ws-соединения |
| `/O<скорость>` | `Normal` (по умолчанию) или `Low` |

`/IBConnectionString` содержит кавычки: всю строку взять в кавычки, внутренние удвоить.

## Аутентификация

| Ключ | Смысл |
| --- | --- |
| `/N<имя>` | Имя пользователя как в списке пользователей Конфигуратора |
| `/P<пароль>` | Пароль. Если пароля нет — можно опустить |
| `/WA<+\|->` | `+` — обязательная аутентификация ОС, `-` — запрет. **По умолчанию `/WA+`** |
| `/WSA<+\|->` | То же для веб-сервера. По умолчанию `/WSA+` |
| `/WSN <имя>`, `/WSP <пароль>` | Учётные данные ОС для веб-сервера при `/WSA+` |
| `/ModifyPassword <пароль>` | Только вместе с `/N` и `/P` — смена пароля при входе |
| `/ResetSavedAuth` | Удалить сохранённый токен повторного входа и запомненные имена |
| `/SAOnRestart` | При перезапуске обязательно спрашивать имя и пароль. Не для тонкого клиента |
| `/OIDA<+\|->` | OpenID-аутентификация. По умолчанию `+` |
| `/AccessToken` | JWT для аутентификации |
| `/Authoff` | OpenID logout |
| `/EmailAuth <email>` | Аутентификация по коду на почту. Не работает в пакетном режиме и при `/DisableStartupDialogs` |

Утечка пароля через argv неустранима — см. SKILL.md.

## Версия, клиент, разрядность

| Ключ | Смысл |
| --- | --- |
| `/AppAutoCheckVersion<+\|->` | Автоподбор версии. По умолчанию `+` |
| `/AppAutoCheckMode` | Автоопределение клиента по данным базы и правам пользователя. При несоответствии перезапускает нужного клиента **той же версии** |
| `/AppArch <разрядность>` | `x86`, `x86_prt` (по умолчанию), `x86_64`, `x86_64_prt` |
| `/RunModeOrdinaryApplication` | Толстый клиент в обычном режиме, невзирая на настройки. Не для тонкого клиента |
| `/RunModeManagedApplication` | Толстый клиент в режиме управляемого приложения; учитывается «Основной режим запуска» из списка баз. **Отключает автоподбор клиента** |

### Алгоритм `/AppAutoCheckVersion` дословно

1. Версия базы определяется по `Version` файла `*.v8i` (файловый вариант) или «по ответу» сервера
   (клиент-серверный вариант).
2. Версии 8.1 и 8.0 — запуск файлов нужной версии; для 8.0 `DESIGNER` → `CONFIG`.
3. Версии 8.2 и выше:
   - **полный номер** → поиск по `InstalledLocation`; нет → поиск дистрибутива по
     `DistributiveLocation`, установка; не найден → **ошибка, запуск прекращается**;
   - **неполный номер** → подстановка через `DefaultVersion` конфигурационных файлов;
     не удалось → максимальный установленный номер и максимальный доступный к установке;
     доступный больше установленного → устанавливается он.

## Строка соединения

Фрагменты `<Имя>=<Значение>`, разделённые `;`. Значение с пробельными символами — в двойных кавычках.

### Общие параметры

| Параметр | Смысл |
| --- | --- |
| `Usr`, `Pwd` | Имя и пароль пользователя. **Та же утечка через argv, что и `/N` `/P`** |
| `LicDstr` | `Y`/`N` — получать клиентскую лицензию через сервер. По умолчанию `N` |
| `prmod` | `1` — привилегированный режим |
| `disstt` | `Y`/`N` — запрет локального распознавания речи. По умолчанию `N` |
| `Zn` | Разделители прикладного решения |

### Файловый вариант

| Параметр | Смысл |
| --- | --- |
| `File` | Каталог с файлом информационной базы |
| `Locale` | Язык/страна |
| `DBFormat` | `8.2.14` (по умолчанию) или `8.3.8` |
| `DBPageSize` | `4096`/`4k`, `8192`/`8k`, `16384`/`16k`, `32768`/`32k`, `65536`/`64k`. По умолчанию `4096` |

### Клиент-серверный вариант

| Параметр | Смысл |
| --- | --- |
| `Srvr` | `[<протокол>://]<адрес>[:<порт>]`. Только TCP. Порт по умолчанию **1541** |
| `Ref` | Имя информационной базы на сервере |
| `DBMS` | `MSSQLServer`, `PostgreSQL`, `IBMDB2`, `OracleDatabase` |
| `DBSrvr`, `DB`, `DBUID`, `DBPwd` | Сервер БД, имя базы, пользователь, пароль |
| `SPwd` | Пароль администратора кластера |
| `SQLYOffs` | `0` или `2000`. По умолчанию `0` |
| `CrSQLDB` | `Y`/`N` — создать базу при отсутствии. По умолчанию `N` |
| `SchJobDn` | `Y`/`N` — блокировка регламентных заданий. По умолчанию `N` |
| `Locale` | Язык/страна |

Допустимые формы адреса `Srvr`:

```
server                              имя, порт по умолчанию
tcp://server:1641                   протокол, имя, порт
127.0.0.1:1541                      IPv4 с портом
[fe10::c47b:90b7:fa32:a2fa%12]      IPv6 в квадратных скобках, с zone id
```

Разбор `Srvr` **нельзя** делать через `split(':')` — IPv6 содержит двоеточия, зона отделяется `%`,
скобки обязательны. Возможно указание нескольких адресов кластера для отказоустойчивости.

### Дополнительные параметры тонкого клиента

`wsn`, `wsp` — учётные данные веб-сервера. `wspauto`, `wspsrv`, `wspport`, `wspuser`, `wsppwd` — прокси.

## Конфигурационные файлы

| Уровень | Файл | Расположение | Кодировка |
| --- | --- | --- | --- |
| Общий | `1cescmn.cfg` | Каталог установки/дистрибутивов | UTF-8 или UTF-16LE |
| Локальный для всех | `1cestart.cfg` | `%ALLUSERSPROFILE%\1C\1CEStart\` | UTF-16LE |
| Локальный | `1cestart.cfg` | `%APPDATA%\1C\1CEStart\` | UTF-16LE |

Linux/macOS: `~/.1C/1cestart`.

Локальный файл меняется при настройках окна запуска. Локальный для всех — только при установке
платформы. `1cescmn.cfg` не может содержать `CommonCfgLocation`.

### Приоритеты — три разных правила

**Значение берётся из ОДНОГО файла, приоритет убывает слева направо:**

| Параметр | Порядок |
| --- | --- |
| `AppAutoInstallLastVersion` | локальный → локальный для всех → общий |
| `UseHwLicenses` | локальный → локальный для всех → общий |
| `InstallComponents` | **локальный для всех → локальный → общий** |
| `AutoUninstall`, `AutoUninstallVersionsAfter` | **общий → локальный → локальный для всех** |

**Объединяются значения из ВСЕХ файлов, возможно несколько строк с одним ключом:**
`CommonCfgLocation`, `CommonInfoBases`, `ConfigurationTemplatesLocation`, `DefaultVersion`,
`DistributiveLocation`, `DontUninstallVersion`.

**`InstalledLocation`** — значения из всех файлов в порядке: общий → локальный для всех → локальный.

### Параметры

| Параметр | Смысл |
| --- | --- |
| `InstalledLocation` | Корень установки платформы. **[Ф]** `C:\Program Files\1cv8` |
| `DefaultVersion` | `<маска>[-<полная версия>][;<разрядность>]`. Таблица подстановки, строк может быть несколько |
| `InstallComponents` | Вложенный список `KEY=0/1` через пробел: `CONFREPOSSERVER`, `CONVERTER77`, `DESIGNERALLCLIENTS`, `LANGUAGES`, `SERVER`, `SERVERCLIENT`, `THINCLIENT`, `THINCLIENTFILE`, `WEBSERVEREXT`. Язык `EN` ставится всегда |
| `AppAutoInstallLastVersion` | `0`/`1`, по умолчанию `1`. Игнорируется, если требуемая версия не установлена — попытка установки будет в любом случае |
| `AutoUninstall` | `0`/`1`, по умолчанию `1` — автоудаление устаревших версий |
| `AutoUninstallVersionsAfter` | Дней до признания версии устаревшей. По умолчанию **90** |
| `DontUninstallVersion` | Версия, защищённая от автоудаления. Строк может быть много |
| `UseHwLicenses` | `1`/`0`, по умолчанию `1`. Платформа сама пишет `0`, если поиск ключа занял более 3 с и пользователь согласился отключить |
| `DisableInstallerVerification` | `1` — отключить проверку подписи установщика. Только Windows |
| `InstallForUsers` | `0`…`3` — режим установки. Только Windows |
| `CommonInfoBases` | Путь к файлу общего списка баз |
| `ConfigurationTemplatesLocation` | Каталог шаблонов конфигураций. Записей может быть больше одной |
| `DistributiveLocation` | Каталог поиска дистрибутивов для автоустановки |
| `InternetService`, `WebCommonInfoBases`, `WebDistributiveLocation` | URL интернет-сервисов. При наличии обоих первым используется `WebCommonInfoBases` |

**[Ф]** В файле на машине ключ записан как `UseHWLicenses`, в документации — `UseHwLicenses`.
Сравнение имён ключей должно быть регистронезависимым.

## Обнаружение установленных версий

**[Ф]** `HKLM\SOFTWARE\1C\1Cv8` и `HKLM\SOFTWARE\WOW6432Node\1C\1Cv8` могут отсутствовать
даже при семи установленных версиях. Реестр — не источник истины.

Порядок: `InstalledLocation` из конфигурационных файлов → подкаталоги → проверка `bin\1cv8.exe`.

**[Ф]** Пример реального набора: `8.3.10.2252`, `8.3.18.1334`, `8.3.20.2290`, `8.3.22.1923`,
`8.3.25.1560`, `8.3.25.1633`, `8.3.27.2214` плюс служебные каталоги `common` и `conf`.

Проверка того, что запустилось на самом деле:

```powershell
Get-CimInstance Win32_Process -Filter "Name='1cv8.exe' OR Name='1cv8c.exe'" |
  Select-Object ProcessId, ExecutablePath, CommandLine
```

## Непроверенное

| Вопрос | Как проверить |
| --- | --- |
| Приоритет `DefaultVersion` над `Version` на практике | Конфликтующие значения → снять `ExecutablePath` |
| Разрешение маски `8.3.25` при двух установленных | Запустить такую базу, снять фактический путь |
| Приоритет уровней для `InstalledLocation` | Разные значения в двух файлах |
| Поведение при `Version=8.3.99.1` и `AppAutoInstallLastVersion=0` | Эксперимент |
| Как определяется версия клиент-серверной базы до подключения | Эксперимент с недоступным сервером |
