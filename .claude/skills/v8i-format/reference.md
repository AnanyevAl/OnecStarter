# .v8i — полный справочник ключей

Источник: ИТС, «Приложение 3. Описание и расположение служебных файлов», версии 8.3.18…8.5.4.
Набор ключей во всех этих версиях идентичен. Пометка **[Ф]** — проверено на реальном файле.

## Шаблон секции

```ini
[Наименование секции]
Connect=            ID=                  OrderInList=         Folder=
OrderInTree=        External=            ClientConnectionSpeed=
App=                AppArch=             DefaultApp=
WA=                 WSA=
Version=            DefaultVersion=      AdditionalParameters=
WebCommonInfoBaseURL=
HttpsCA=            HttpsCert=           HttpsCAFile=         HttpsCertFile=
HttpsCertSelect=
ShowInList=         MobilePublicKey=     WebCommonInfoBases=  InternetService=
UseProxy=           PSrv=                PPort=               PUser=          PPasswd=
StartupErrorHelpURL=                     StartupErrorHelpText=
```

## Обязательные

| Ключ | Смысл |
| --- | --- |
| Наименование секции | Совпадает с наименованием базы. Отдельного ключа для имени нет |
| `Connect` | Строка соединения. Отсутствие означает, что секция — группа дерева |
| `ID` | UUID, уникален в рамках файла. Ручное формирование не рекомендуется. Ключ слияния |

Допустимы несколько секций с одинаковой `Connect` и разными именами — запуск одной базы
в разных режимах без изменения её свойств.

## Дерево и порядок

| Ключ | Значения | Смысл |
| --- | --- | --- |
| `Folder` | `/`, `/Клиенты`, `/Клиенты/Розница` | Папка в дереве. Разделитель `/`. Не указан или опущен → база в корне |
| `OrderInList` | дробное, **[Ф]** `60.6814814814813`, `-1`, `311296` | Порядок при представлении списком |
| `OrderInTree` | целое, **[Ф]** `768`, `1024`, `16640` | Порядок в ветви при представлении деревом |
| `External` | `0` / `1` | Запись получена из внешнего источника |

## Клиент и версия

| Ключ | Значения | Смысл |
| --- | --- | --- |
| `App` | `Auto`, `ThinClient`, `ThickClient`, `WebClient` | Тип клиента. Задаётся в свойствах базы |
| `DefaultApp` | `ThinClient`, `ThickClient` | Тип клиента, определённый автоматически при `/AppAutoCheckMode` |
| `AppArch` | `x86`, `x86_prt`, `x86_64`, `x86_64_prt` | Разрядность. Значения совпадают с ключом `/AppArch` |
| `Version` | полный или неполный номер | Версия, которая должна использоваться |
| `DefaultVersion` | полный номер | Версия, реально использованная при последнем запуске. **Приоритетнее `Version`** |

Логика `DefaultApp`: при `App=Auto` и отсутствии `DefaultApp` запускается тонкий клиент
с `/AppAutoCheckMode`. Если `DefaultApp` задан — запускается указанный в нём клиент, тоже
с `/AppAutoCheckMode`.

## Аутентификация

| Ключ | Значения | Смысл |
| --- | --- | --- |
| `WA` | `1` / `0` | `1` — пытаться аутентификацию средствами ОС, при неудаче запросить логин/пароль. `0` — всегда логин/пароль |
| `WSA` | `1` / `0` | То же для веб-сервера (тонкий клиент через веб-сервер, веб-клиент) |

`WA=1` — это «пытаться», а не «требовать». Ключ командной строки `/WA+` означает
обязательную аутентификацию ОС. Семантика не совпадает, прямое отображение `WA=1 → /WA+` неверно.

## Соединение и параметры запуска

| Ключ | Значения | Смысл |
| --- | --- | --- |
| `ClientConnectionSpeed` | `Normal`, `Low` | Только для тонкого и веб-клиентов. Не указан → берётся из флажка окна запуска |
| `AdditionalParameters` | строка | Дополнительные параметры запуска из свойств базы, например `/TechnicalSpecialistMode` |

## Прокси — только для ws-соединения

| Ключ | Значения | Смысл |
| --- | --- | --- |
| `UseProxy` | `0` / `1` / `2` | `0` — не использовать, `1` — автоопределение, `2` — явные настройки. Не указан → автоопределение |
| `PSrv` | адрес | Обязателен при `UseProxy=2` |
| `PPort` | порт | Обязателен при `UseProxy=2` |
| `PUser` | имя | Пользователь прокси |
| `PPasswd` | base64 | **Зашифрованный** пароль. Алгоритм не документирован — читать и писать как непрозрачную строку |

Для файлового и клиент-серверного вариантов эти ключи смысла не имеют.

## HTTPS-сертификаты

| Ключ | Значения |
| --- | --- |
| `HttpsCA` | `None`, `File`, `Windows`, `Linux`, `macOS` — источник сертификатов УЦ |
| `HttpsCert` | `None`, `File`, `Windows`, `Linux`, `macOS` — источник клиентского сертификата |
| `HttpsCAFile` | Путь к файлу с сертификатами УЦ. Тип `File` + пустой путь → трактуется как `None` |
| `HttpsCertFile` | Путь к файлу с клиентским сертификатом. То же правило |
| `HttpsCertSelect` | `Recent`, `Choose`, `Auto` — способ выбора сертификата Windows |

## Диагностика ошибок подключения

| Ключ | Смысл |
| --- | --- |
| `StartupErrorHelpURL` | URL гиперссылки «Нужна помощь?» в диалоге ошибки |
| `StartupErrorHelpText` | Текст-подсказка. Простая строка либо сериализованная форматированная строка (`СериализаторXDTO.XMLСтрока`) |

## Веб-списки

| Ключ | Смысл |
| --- | --- |
| `WebCommonInfoBaseURL` | Адрес интернет-сервиса, из которого база попала в список |

При удалении `InternetService` или `WebCommonInfoBases` из `1cestart.cfg` записи из удалённых
источников исчезают из списка.

## Только для мобильного клиента

`ShowInList` (`1`/`0`, по умолчанию `0`), `MobilePublicKey` (MD5 открытого ключа в Base64),
`InternetService`, `WebCommonInfoBases`, `DisplayAuthDialog`, `DisableUseBiometrics`,
`UseBiometrics` (по умолчанию `1`), `DisableRememberMe`, `RememberMe` (по умолчанию `1`).

В десктопном сценарии не встречаются, но при разборе должны сохраняться.

## Строка соединения `Connect`

Последовательность фрагментов `<Имя>=<Значение>`, разделённых `;`.
Если значение содержит пробельные символы — заключается в двойные кавычки.

**[Ф]** На практике `File` закавычен всегда, даже без пробелов.

```ini
Connect=File="D:\db\buh";
Connect=Srvr="srv-1c:1541";Ref="buh";
Connect=ws="http://web-server/resource/";
```

Полный набор параметров строки соединения — в скиле `platform-launch`.

## Наблюдения на реальном файле

**[Ф]** Файл на машине разработчика: 610 строк, 59 секций (53 базы + 6 групп), UTF-8 без BOM,
пустых строк и комментариев нет, дубликатов `ID` нет.

Из 30+ задокументированных ключей реально встречаются 13: `ID`, `OrderInList`, `OrderInTree`,
`Folder`, `External`, `Connect`, `App`, `WA`, `AppArch`, `Version`, `ClientConnectionSpeed`,
`DefaultVersion`, `DefaultApp`.

Отсюда правило: **отсутствие ключа в конкретном файле не означает, что ключа нет в формате.**

## Непроверенное

| Вопрос | Как проверить |
| --- | --- |
| Держит ли `1cestart.exe` файл заблокированным во время работы | Открыть стартер, попытаться записать |
| Полный набор ключей, которые платформа дописывает сама | Менять свойства базы в стартере, снимать diff |
| Экранирование кавычек внутри значений `Connect` | База в каталоге с кавычкой в имени |
| Как штатный стартер обходится с секцией без `Connect`, добавленной вручную | Эксперимент |
