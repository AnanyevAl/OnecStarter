# OneCStarter

[![CI](https://github.com/AnanyevAl/OnecStarter/actions/workflows/ci.yml/badge.svg)](https://github.com/AnanyevAl/OnecStarter/actions/workflows/ci.yml)

> Fast launcher for 1C:Enterprise infobases on Windows: tree, search,
> explicit platform version control, local 1C server management,
> 1C:EDT workspaces with CLI import. Russian UI; docs below are in Russian.

Программа запуска информационных баз 1С:Предприятие для специалистов.
Три раздела в одном окне: «Базы» — список баз с явным контролем версии
платформы, «Серверы» — локальные серверы 1С для разработки, «EDT» — рабочие
области 1C:EDT с запуском нужной версии и командами `1cedtcli.exe`.
Список баз — тот же `ibases.v8i`, что у штатного стартера: после любой
операции файл остаётся рабочим для 1CEStart, удаление OneCStarter ничего
не теряет.

## Базы

- **Дерево и поиск.** Группы как в файле, «Избранное» и «Недавние» сверху,
  порядок — по алфавиту или как в файле. Поиск по имени (`Ctrl+F`, крестик
  очистки); `Enter` в поиске запускает первую найденную.
- **Версия платформы.** Колонка версии у каждой базы, не установленные версии
  подсвечены, при запуске версия выбирается явно. У веб- и клиент-серверных баз
  версию решает сервер — колонка так и говорит («веб», «сервер»), своя версия
  не навязывается. Знание о версиях платформы — данные, не код: выход новой
  версии не требует обновления программы.
- **Запуск.** `Enter`/`F3` — 1С:Предприятие, `F4` — конфигуратор, `Ctrl+1/2/3` —
  тонкий, толстый клиент, конфигуратор; ярлыки на базы; сворачивание в трей при
  запуске; глобальная горячая клавиша для окна.
- **Веб-базы.** Базу, опубликованную на веб-сервере, открывает тонкий клиент
  или браузер — решает ключ `App` записи (его читает и штатный стартер), для
  записей без него — настройка «Веб-базы открывать». Разовый выбор — в
  контекстном меню.
- **Логин и пароль.** Включается для конкретной записи. Логин — в наших данных,
  пароль — в диспетчере учётных данных Windows (DPAPI). Цена: у GUI-клиента 1С
  нет входа через stdin, пароль передаётся в командной строке (`/P`) и **виден
  любой программе под вашей учётной записью всё время работы клиента** —
  программа предупреждает об этом при сохранении.
- **Доступность файловых баз.** Каталог, исчезнувший с диска (съёмный носитель,
  сетевая шара), виден до запуска: крестик на значке и «(нет каталога)» в строке.
  Проверка идёт в фоне при старте и по `F5`, без таймера — чтобы не будить
  внешние диски и VPN.
- **Правка списка.** Drag&drop каталога файловой базы в окно с автозаполнением
  полей; `Alt+Enter` — свойства записи или группы, `Insert` — новая база в группу
  текущей строки, `Delete` — удалить (с подтверждением), `Alt+↑/↓` — переставить.
  Путь в панели снизу — ссылка: клик открывает каталог, правая кнопка —
  «Копировать». Справочник всех сочетаний — в настройках.

## Серверы

Локальные серверы 1С для разработки — из того же окна: профиль сервера
(версия `ragent`, порты, каталог кластера, `-debug`/`-http`), запуск
и остановка всего дерева одним действием, журнал профиля с событиями
и выводом сервера, смена версии консоли администрирования. Чужие серверы
на машине и держатели портов профиля видны и подсвечены — запуск в занятый
порт отказывает словами, а не падением. Дерево сервера живёт в Job Object
запуска: выход из лаунчера не оставляет процессов-сирот (при работающих
серверах выход спрашивает подтверждение).

## EDT

![Раздел «EDT»: рабочие области с версией EDT и памятью, панель путей, консоль CLI](docs/assets/screenshot-edt.png)

**Записи.** Список рабочих областей 1C:EDT с группами. У записи — версия EDT
(точное совпадение с установленной), JVM, память (действующий `-Xmx` — в колонке
«Память») и язык. «Открыть в EDT» запускает нужную версию с правильной JVM,
повторный запуск переключает на открытое окно (зелёный ▶ у имени — EDT запущен).
«Открыть в VS Code» / «Открыть в Antigravity» открывают каталог проекта (может
лежать вне рабочей области). Записи можно импортировать из EDT Start — вручную,
только новые; реестр EDT Start только читается, список хранится в
`%APPDATA%\OneCStarter\edt.json`.

**CLI.** Подменю «CLI» — сборка, импорт, проверка и информация по проектам через
`1cedtcli.exe` с выводом в сворачиваемую консоль; работает только на рабочей
области, не открытой в EDT (иначе CLI вернёт код 202). Перечень проектов для
проверки берётся из реестра рабочей области (`.metadata`), а не из подкаталогов —
проекты EDT обычно лежат снаружи.

**Импорт проектов.** «Импортировать проекты…» подставляет каталог проекта
записи, находит в нём проекты EDT так же, как мастер импорта самой EDT (каталоги
с `.project`, до трёх уровней вглубь) и показывает их с флажками; уже привязанные
к рабочей области недоступны. Отмеченные импортируются одним сеансом CLI — скрипт
`-file` с JDK через `-ini-file`: два проекта — около минуты вместо ~48 с на каждый
порознь (каждый запуск CLI поднимает headless-Eclipse). При ошибке скрипт
останавливается на первой неудавшейся команде (код 204), текст ошибки — в журнале.

**Клавиши.** `Enter` — открыть в EDT, `Alt+Enter` — изменить запись или группу,
`Insert` — добавить запись в группу текущей строки, `Delete` — удалить, `F5` —
обновить установки и состояние.

## Настройки

Тема (тёмная, светлая, как в системе), глобальная горячая клавиша окна,
поведение трея и автозапуск, клиент по умолчанию и веб-базы, размер истории,
корень каталогов серверов, JVM и редакторы для EDT, справочник сочетаний
разделов «Базы» и «EDT», версия программы и ссылка на репозиторий.
Настройки применяются сразу и хранятся в `%APPDATA%\OneCStarter\settings.json`.

## Установка

Последний выпуск — на странице
[Releases](https://github.com/AnanyevAl/OnecStarter/releases/latest):

- **Установщик:** `OneCStarter-<версия>-setup.exe` — per-user, права
  администратора не нужны.
- **Portable:** распаковать `OneCStarter-<версия>-portable.zip`, запустить
  `OneCStarter.exe`.

SmartScreen при первом запуске предупредит о неизвестном издателе:
сборки не подписаны (сертификата нет). Исходники открыты — сборку можно
воспроизвести самостоятельно (см. ниже). Настройки и списки хранятся
в `%APPDATA%\OneCStarter` и при обновлении сохраняются.

## Диагностика

Лог: `%APPDATA%\OneCStarter\logs\onecstarter.log`. Если приложение
не стартует — запустите `OneCStarterc.exe` (консольная сборка) и приложите
вывод к issue.

## Сборка из исходников

```powershell
uv sync
uv run pytest
powershell -File build/build.ps1
```

Установщик требует Inno Setup 6. Без него — сборка только portable-варианта:
`powershell -File build/build.ps1 -SkipInstaller`.

Устройство исходников и правила для изменений — [CONTRIBUTING.md](CONTRIBUTING.md).
Требования и решения по каждой функции — [docs/requirements.md](docs/requirements.md).

## Границы

1С:Предприятие 7.7 не поддерживается; телеметрии и любого сбора данных нет.
Пароль сохраняется только если вы это включили для конкретной записи, и только
в диспетчере учётных данных Windows — свои файлы программы секретов не хранят
(см. «Логин и пароль» выше).
