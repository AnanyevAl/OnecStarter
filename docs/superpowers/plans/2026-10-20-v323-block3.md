# 3.2.3, блок 3 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** проверка новой версии на GitHub с явного согласия, полоса-уведомление и установка по кнопке
с проверкой SHA-256 (T-25).

**Architecture:** чистая логика (`domain/update.py`) → сеть и файлы с подменяемым HTTP
(`services/update.py`) → Qt-обвязка (`ui/update.py`: потоки, полоса, контроллер) → проводка
(`ui/app.py`, `ui/shell.py`, `ui/settings_view.py`).

**Спека:** [2026-10-20-v323-block3-update-check-design.md](../specs/2026-10-20-v323-block3-update-check-design.md).

## Global Constraints

- Адрес `https://api.github.com/repos/AnanyevAl/OnecStarter/releases/latest`; заголовки только
  `User-Agent: OneCStarter/<версия>` и `Accept: application/vnd.github+json`; таймаут 10 с.
- Ни одного реального сетевого запроса и запуска процесса в тестах — HTTP, запуск файла и выход
  подменяются аргументами.
- Без согласия (`check_updates` не `True`) фоновой проверки нет. Тихий старт в трей — ни вопроса, ни проверки.
- Установщик запускается только после совпадения SHA-256 и подтверждения выхода.
- ruff: писать без `noqa`, затем `ruff check --add-noqa <файл>`; mypy — без конвейера.

### Task 1: `domain/update.py`

Чистые функции, табличные тесты `tests/unit/test_update_domain.py`.

```python
@dataclass(frozen=True)
class Release:
    version: str          # тег без ведущей «v»
    page_url: str         # html_url
    setup_name: str | None
    setup_url: str | None  # browser_download_url ассета *-setup.exe
    setup_digest: str | None  # «sha256:<hex>» или None

def version_tuple(text: str) -> tuple[int, ...] | None   # "v3.2.4" → (3, 2, 4); иначе None
def is_newer(latest: str, current: str) -> bool          # неразбираемое — False
def parse_release(payload: object) -> Release            # ValueError на чужой форме
def sha256_matches(data: bytes, digest: str | None) -> bool  # None/не sha256 → False
```

Тесты: `v3.2.4`/`3.2.4`/`3.2`/`3.2.4-rc1`→None/`abc`→None; `is_newer("3.2.4","3.2.3")`, равные, меньшие,
`("3.10.0","3.9.9")`, неразбираемые; `parse_release` с ассетом установщика, без него, без `digest`,
не словарь / без `tag_name` → `ValueError`; `sha256_matches` верный, неверный, `None`, `md5:…`.

### Task 4: `ui/update.py` — потоки, полоса, контроллер

- `UpdateChecker(QObject)`: `found(object)`, `up_to_date()`, `failed(str)`; `start()` — в демоне
  (`spawn` подменяем), сравнение с `current_version`.
- `UpdateDownloader(QObject)`: `ready(object Path)`, `failed(str)`; `start(release)`.
- `UpdateBanner(QWidget)`: `show_release(release, installable)`, кнопки «Установить» (`install_requested`),
  «Что нового» (`open_url(release.page_url)`), «×» (скрыть); `show_downloading()`, `show_error(text)`.
- `UpdateController`: собирает всё; аргументы — `store`, `banner`, `checker`, `downloader`,
  `installable: bool`, `ask_consent: Callable[[], bool]`, `confirm_quit: Callable[[], bool]`,
  `launch: Callable[[Path], None]`, `quit: Callable[[], None]`, `on_status: Callable[[str], None]`.
  - `start_on_launch(window_shown: bool)`: `None` + окно показано → вопрос → `store.update(check_updates=ответ)`;
    `True` → `checker.start()`; иначе ничего.
  - `check_now()`: ручная проверка, статус в `on_status` («Установлена последняя версия», «Вышла версия X»,
    «Не удалось проверить: …»).
  - найдена версия → `banner.show_release(...)`; «Установить» → `downloader.start`; `ready(path)` →
    `confirm_quit()` → `launch(path)` → `quit()`; отказ — ничего.

Тесты `tests/ui/test_update.py` (синхронный `spawn`, фейковые http/launch/quit): полоса и кнопка
«Установить» только при `installable`; × скрывает; согласие «Да» сохраняет `True` и проверяет,
«Нет» сохраняет `False` и не проверяет (**мутация**: проверять при `False`), окно скрыто — не спрашивает;
ручная проверка пишет статус для трёх исходов; установка: подтверждение «Нет» — `launch` не вызван,
«Да» — `launch(path)` затем `quit`; неверный digest — `launch` не вызван, полоса показывает ошибку.

### Task 5: проводка

  `launch = os.startfile`, `quit = application.quit`, `confirm_quit = window.confirm_quit or (lambda: True)`,
  `ask_consent` — `ask_confirmation(window, "Обновления", …)`), `window.set_banner(banner)`,
  `settings_view.check_updates_requested → controller.check_now`, статус → `settings_view.show_update_status`;
  ссылка на контроллер на окне. В `main()` после показа окна — `controller.start_on_launch(window.isVisible())`.
- Тесты: `tests/ui/test_shell.py` — полоса стоит над разделами; `tests/ui/test_settings_view.py` (поштучно) —
  флажок отражает настройку и пишет её, кнопка шлёт сигнал, статус показывается; `tests/ui/test_app.py` — сборка
  окна не стартует проверку.
