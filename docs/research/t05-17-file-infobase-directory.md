# T-05.17 — файл базы данных в каталоге файловой ИБ

> Замер 10.09.2026, машина заказчика, **косвенный — через smoke собранного
> экземпляра v2.4.0**, а не через листинг каталога. Повод — веха v2.4
> ([спека](../superpowers/specs/2026-09-09-v24-file-availability-design.md), §0):
> проба доступности считает базу живой, только если в её каталоге есть файл
> `DB_FILE_NAME = "1Cv8.1CD"`. Процессы 1С агент не запускал; smoke выполнил
> заказчик.

## Что утверждалось и на каком основании

| Утверждение | До замера | После |
| --- | --- | --- |
| Каталог файловой ИБ содержит файл базы данных `1Cv8.1CD` | **[Д]** из документации — ИТС, Приложение 7, ключ `/F <каталог>` («Каталог с файлом `1Cv8.1CD`»), `platform-launch/reference.md` | **[Ф]** — см. методику |
| Регистр имени на диске | **[?]** | **[?]** — листинг не снимался; для `stat` на Windows безразличен |
| Поведение платформы на каталоге без этого файла | **[?]** | **[?]** — не проверялось; на корректность пробы не влияет, подтверждало бы лишь разумность решения «ловить пустой каталог» (спека §2) |

## Методика

Собранный `dist/OneCStarter/OneCStarter.exe` 2.4.0 (коммит `6eda4f6`,
сборка `build/build.ps1`, автоматический smoke OK) запущен заказчиком
на рабочем списке баз. Проба (`services/availability.py`, `_probe_one`)
для каждой файловой базы с абсолютным путём делает два вызова:
`stat(<каталог>)` и `stat(<каталог>/1Cv8.1CD)`; любой отказ второго —
`MISSING`, то есть крестик и суффикс «(нет каталога)».

Проверки заказчика 10.09.2026:

1. **База с удалённым каталогом** — крестик на значке, суффикс, подсказка
   с путём. Ожидалось, подтверждено.
2. **`F5` после восстановления каталога** — метка снята; **живые базы
   без метки**. Ожидалось, подтверждено.
3. База только из общего списка (`CommonInfoBases`) помечена при старте
   без `F5` (проверка правки I-1 финального ревью) — **не проверялась**:
   общих списков на машине нет. Покрыто тестом
   `test_common_lists_ready_starts_the_probe_a_second_time`.

## Вывод

Из п. 2 следует прямо: для каждой живой файловой базы заказчика
`stat(<каталог>/1Cv8.1CD)` завершился успехом — файл с таким именем (с точностью
до регистра, который NTFS не различает) в каталоге **есть**. Будь имя из ИТС
неверным, весь список загорелся бы крестиками при первом запуске. Это измерение
на реальной машине, пусть и косвенное; утверждение о существовании файла
переводится в **[Ф]**.

Регистр и поведение платформы на каталоге без файла остаются **[?]** —
и остаются вне вехи: на работу пробы они не влияют.
