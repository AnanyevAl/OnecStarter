## Режимы запуска

**[Д]** Одновременное использование нескольких режимов не допускается.

```
1cv8 ENTERPRISE [<параметры запуска>]
1cv8 DESIGNER [<команды>]
1cv8 CREATEINFOBASE <строка соединения> [/AddToList [<имя ИБ>]] [/UseTemplate <файл>] ...
```

## Параметры подключения

| Ключ | Смысл |
| --- | --- |
| `/F <каталог>` | **[Д]** Каталог с файлом `1Cv8.1CD` |
| `/S <адрес>` | **[Д]** `<сервер>/<имя ИБ>`. Разделитель `/` работает везде; `\` — только Windows; `"server\ib"` — везде |
| `/IBName <имя>` | **[Д]** Поиск базы по имени в списке. **Если баз с таким именем больше одной — запуск прекращается с ошибкой.** Кавычки в имени удваиваются: `База ""СтройТорг""` |
| `/IBConnectionString <строка>` | **[Д]** Строка соединения целиком. Части могут быть переопределены другими параметрами, **если те стоят в командной строке позже** |
| `/WS <url>` | **[Д]** Строка ws-соединения |
| `/O<скорость>` | **[Д]** `Normal` (по умолчанию) или `Low` |

> **[Д]** `/IBConnectionString` содержит кавычки. Вся строка берётся в кавычки, внутренние
> кавычки удваиваются.

## Аутентификация

| Ключ | Смысл |
| --- | --- |
| `/N<имя>` | **[Д]** Имя пользователя как в списке пользователей Конфигуратора |
| `/P<пароль>` | **[Д]** Пароль. Если пароля нет — можно опустить |
| `/WA<режим>` | **[Д]** `+` — обязательная аутентификация ОС, `-` — запрет. **По умолчанию `/WA+`** |
| `/WSA<режим>` | **[Д]** То же для веб-сервера. По умолчанию `/WSA+` |
| `/WSN <имя>`, `/WSP <пароль>` | **[Д]** Учётные данные ОС для веб-сервера при `/WSA+` |
| `/ResetSavedAuth` | **[Д]** Удалить сохранённый токен повторного входа и запомненные имена |
| `/SAOnRestart` | **[Д]** При перезапуске обязательно спрашивать имя и пароль. Не используется в тонком клиенте |

> ### Пароль в командной строке — неустранимая утечка
>
> Аргументы процесса читаются любым процессом того же пользователя
> (`Get-CimInstance Win32_Process | Select CommandLine`). Пароль в `/P` виден всё время работы клиента.
>
> Альтернативы нет: у GUI-клиента 1С нет аутентификации через stdin. Параметры `Usr`/`Pwd`
> строки соединения имеют ту же проблему — строка тоже передаётся в argv.
>
> Что из этого следует: хранить пароли только в Windows Credential Manager (DPAPI);
> функция «запомнить пароль» выключена по умолчанию; пользователь предупреждается явно.

## Подбор версии — `/AppAutoCheckVersion`

**[Д]** `+` — выполнять подбор (по умолчанию), `-` — не выполнять.
`/AppAutoCheckVersion` эквивалентно `/AppAutoCheckVersion+`.

Алгоритм дословно по документации:

1. **Определяется версия запускаемой базы** — по параметру `Version` файла `*.v8i`
   (файловый вариант) либо «по ответу» сервера (клиент-серверный вариант).
2. **Версии 8.1 и 8.0** — определяется местоположение файлов нужной версии и запускается она.
   Для 8.0 параметр `DESIGNER` заменяется на `CONFIG`.
3. **Версии 8.2 и выше:**
   - **Номер полный** → поиск версии по `InstalledLocation` конфигурационных файлов.
     Не установлена → поиск дистрибутива по `DistributiveLocation`. Найден → установка.
     Не найден → **запуск прекращается с ошибкой**.
   - **Номер неполный** → попытка получить полный номер через `DefaultVersion` конфигурационных
     файлов. Не удалось → ищется максимальный номер среди установленных (`InstalledLocation`)
     и максимальный доступный к установке (`DistributiveLocation`). Если доступный больше
     установленного — **устанавливается версия с большим номером**.

> Важное для нас: в клиент-серверном варианте версию диктует **сервер**, а не `.v8i`.
> Определить её локально до подключения нельзя **[?]**.

### Приоритет источников версии

**[Д]** Из «Приложения 3»: `DefaultVersion` в секции базы `.v8i` — версия, реально использованная
при последнем запуске; **при последующих запусках используется она, а не `Version`**.

Итоговый порядок для файлового варианта:

```
DefaultVersion (секция базы .v8i)     ← реально использованная в прошлый раз, ПРИОРИТЕТНЕЕ
  ↓ нет
Version (секция базы .v8i)            ← может быть НЕПОЛНОЙ
  ↓ неполная
DefaultVersion (конфигурационные файлы)  ← правила подстановки, см. ниже
  ↓ не разрешилось
максимальная установленная
```

### Сравнение версий

Покомпонентное числовое, не лексикографическое.
**[Ф]** Контрпример из установленного набора: лексикографически `8.3.9` > `8.3.18` > `8.3.10`,
числовой порядок обратный.

**[Ф]** Разрешение неполной версии: `8.3.25` при установленных `8.3.25.1560` и `8.3.25.1633`
должно дать `8.3.25.1633` — максимальную с этим префиксом.

## Выбор клиента — `/AppAutoCheckMode`

**[Д]** Автоматическое определение приложения по данным базы:

1. Определяется режим запуска конкретного пользователя.
2. Определяется основной режим запуска базы.
3. Если определённый режим не соответствует запущенному клиенту **и** у пользователя есть право
   на запуск нужного клиента — выполняется **перезапуск нужного клиента той же версии**.
   Иначе продолжается загрузка текущего.

| Ключ | Смысл |
| --- | --- |
| `/RunModeOrdinaryApplication` | **[Д]** Толстый клиент в обычном режиме, невзирая на настройки конфигурации и пользователя. Не используется в тонком клиенте |
| `/RunModeManagedApplication` | **[Д]** Толстый клиент в режиме управляемого приложения; учитывается настройка «Основной режим запуска» из списка баз. **Отключает механизм автоподбора клиента** |

## Строка соединения

**[Д]** Последовательность фрагментов `<Имя>=<Значение>`, разделённых `;`.
**Если значение содержит пробельные символы — оно заключается в двойные кавычки.**

**[Ф]** На реальном файле значение `File` закавычено всегда, даже без пробелов:
`Connect=File="C:\Bases\Demo";`

### Файловый вариант

| Параметр | Смысл |
| --- | --- |
| `File` | Имя каталога с файлом информационной базы |
| `Locale` | Язык/страна |
| `DBFormat` | `8.2.14` (по умолчанию) или `8.3.8` |
| `DBPageSize` | `4096`/`4k` … `65536`/`64k`, по умолчанию `4096` |

### Клиент-серверный вариант

| Параметр | Смысл |
| --- | --- |
| `Srvr` | `[<протокол>://]<адрес>[:<порт>]`. Только TCP. Порт по умолчанию **1541** |
| `Ref` | Имя информационной базы на сервере |
| `DBMS` | `MSSQLServer`, `PostgreSQL`, `IBMDB2`, `OracleDatabase` |
| `DBSrvr`, `DB`, `DBUID`, `DBPwd` | Параметры сервера БД |
| `SPwd` | Пароль администратора кластера |
| `SQLYOffs` | `0` или `2000` |
| `CrSQLDB`, `SchJobDn` | `Y`/`N` |

**[Д]** Форматы адреса `Srvr` — все допустимы:

```
server                              имя, порт по умолчанию
tcp://server:1641                   протокол, имя, порт
127.0.0.1:1541                      IPv4 с портом
[fe10::c47b:90b7:fa32:a2fa%12]      IPv6 в квадратных скобках, с zone id
```

> Разбор `Srvr` **нельзя** делать через `split(':')` — IPv6 содержит двоеточия,
> а зона отделяется `%`. Скобки обязательны для IPv6.

**[Д]** Возможно указание нескольких адресов кластера для отказоустойчивости.

## Конфигурационные файлы

**[Д]** Три уровня, не два:

| Уровень | Файл | Расположение |
| --- | --- | --- |
| Общий | `1cescmn.cfg` | Каталог, откуда выполняется установка (сетевой каталог дистрибутивов) |
| Локальный для всех пользователей | `1cestart.cfg` | `%ALLUSERSPROFILE%\1C\1CEStart\` |
| Локальный | `1cestart.cfg` | `%APPDATA%\1C\1CEStart\` |

**[Д]** `1cestart.cfg` — **UTF-16LE**. `1cescmn.cfg` — **UTF-8 или UTF-16LE**.
**[Ф]** Оба `1cestart.cfg` на машине — UTF-16LE с BOM (`FF FE`).

**[Д]** Локальный файл изменяется при настройках окна запуска. Локальный для всех пользователей —
только во время установки платформы. `1cescmn.cfg` не может содержать `CommonCfgLocation`.

### Приоритеты — три разных правила

Наивный merge словарей неверен. Правила различаются по параметрам:

**Значение берётся из ОДНОГО файла, приоритет убывает:**

| Параметр | Порядок |
| --- | --- |
| `AppAutoInstallLastVersion` | локальный → локальный для всех → общий |
| `UseHwLicenses` | локальный → локальный для всех → общий |
| `InstallComponents` | **локальный для всех → локальный → общий** |
| `AutoUninstall`, `AutoUninstallVersionsAfter` | **общий → локальный → локальный для всех** |

**Используются значения из ВСЕХ файлов (объединение, возможно несколько строк с одним ключом):**

`CommonCfgLocation`, `CommonInfoBases`, `ConfigurationTemplatesLocation`, `DefaultVersion`,
`DistributiveLocation`, `DontUninstallVersion`

**`InstalledLocation`** — **[Д]** «используются значения из всех файлов в следующем порядке»:
общий → локальный для всех → локальный.

> Три разных порядка приоритета в одном формате. Нужна явная таблица по каждому ключу,
> а не общее правило.

### `DefaultVersion` — это правило подстановки, а не «версия по умолчанию»

**[Д]** Допускается **несколько строк**. Грамматика: `<маска>[-<полная версия>][;<разрядность>]`

```ini
DefaultVersion=8.3-8.3.24.100      ; база просит 8.3      → запустить 8.3.24.100
DefaultVersion=8.2.15-8.2.15.315   ; база просит 8.2.15   → запустить 8.2.15.315
DefaultVersion=8.3;x86_64_prt      ; любая база → клиент 8.3, преимущественно 64 бита
```

Это **таблица соответствий**, а не скаляр. Почти все вторичные источники описывают этот
параметр как «версия по умолчанию» — неверно.

### Прочие параметры

| Параметр | Смысл |
| --- | --- |
| `InstalledLocation` | **[Ф]** `C:\Program Files\1cv8` |
| `InstallComponents` | Вложенный список `KEY=0/1` через пробел. Компоненты: `CONFREPOSSERVER`, `CONVERTER77`, `DESIGNERALLCLIENTS`, `LANGUAGES`, `SERVER`, `SERVERCLIENT`, `THINCLIENT`, `THINCLIENTFILE`, `WEBSERVEREXT`. **[Д]** Язык `EN` ставится всегда |
| `AppAutoInstallLastVersion` | `0`/`1`, по умолчанию `1`. **[Д]** Игнорируется, если требуемая версия не установлена — попытка установки будет в любом случае |
| `AutoUninstall` | `0`/`1`, по умолчанию `1` — автоудаление устаревших версий |
| `AutoUninstallVersionsAfter` | Дней до признания версии устаревшей, по умолчанию **90** |
| `DontUninstallVersion` | Версия, защищённая от автоудаления. Строк может быть много |
| `UseHwLicenses` | `1`/`0`, по умолчанию `1`. **[Д]** Платформа сама меняет значение: при долгом (>3 с) безуспешном поиске ключа предлагает отключить и пишет `0` |
| `DisableInstallerVerification` | `1` — отключить проверку цифровой подписи установщика. Только Windows |
| `InstallForUsers` | `0`…`3` — режим установки. Только Windows |
| `CommonInfoBases` | Путь к файлу общего списка баз |
| `InternetService`, `WebCommonInfoBases`, `WebDistributiveLocation` | URL интернет-сервисов. **[Д]** При наличии обоих первым используется `WebCommonInfoBases` |

**[Ф]** Реальное содержимое на машине:

```ini
; ProgramData (локальный для всех), UTF-16LE
InstalledLocation=C:\Program Files\1cv8
InstallComponents=DESIGNERALLCLIENTS=1 THINCLIENTFILE=1 THINCLIENT=1 WEBSERVEREXT=1 SERVER=1 ...

; APPDATA (локальный), UTF-16LE
ConfigurationTemplatesLocation=D:\1c-templates
UseHWLicenses=0
AppAutoInstallLastVersion=0
```

> **[Ф]** В файле ключ записан как `UseHWLicenses`, в документации — `UseHwLicenses`.
> Сравнение имён ключей должно быть регистронезависимым.

## Открытые вопросы

| # | Вопрос | Как проверить |
| --- | --- | --- |
| 1 | Приоритет `DefaultVersion` над `Version` в секции базы — на практике | Задать конфликтующие значения, снять `Win32_Process.ExecutablePath` |
| 2 | Разрешение маски `8.3.25` при двух установленных | **[Ф]** такая база уже есть в списке — запустить и снять фактический путь |
| 3 | Приоритет уровней для `InstalledLocation` | Задать разные значения в двух файлах |
| 4 | Поведение при `Version=8.3.99.1` и `AppAutoInstallLastVersion=0` | Эксперимент |
| 5 | Как определяется версия для клиент-серверной базы до подключения | Эксперимент с недоступным сервером |

Инструмент проверки:

```powershell
Get-CimInstance Win32_Process -Filter "Name='1cv8.exe' OR Name='1cv8c.exe'" |
  Select-Object ProcessId, ExecutablePath, CommandLine
```
