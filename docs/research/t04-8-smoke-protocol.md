## Подготовка (один раз)

1. Резервные копии (кэши не бэкапим — их и чистим; настройки и список — да):

   ```powershell
   Copy-Item "$env:APPDATA\1C\1CEStart\ibases.v8i" "$env:APPDATA\1C\1CEStart\ibases.v8i.bak-t048"
   Copy-Item "$env:APPDATA\OneCStarter\settings.json" "$env:APPDATA\OneCStarter\settings.json.bak-t048"
   ```

2. «**Адрес кэшей empty**» (ID в протокол не пишем — извлекается на месте):

   ```powershell
   $id = $null; $in = $false
   foreach ($line in Get-Content "$env:APPDATA\1C\1CEStart\ibases.v8i") {
     if ($line -match '^\[(.*)\]$') { $in = ($Matches[1] -eq 'empty') }
     elseif ($in -and $line -match '^ID=(.+)$') { $id = $Matches[1]; break }
   }
   $prog = "$env:LOCALAPPDATA\1C\1Cv8\$id"; $user = "$env:APPDATA\1C\1Cv8\$id"
   ```

3. «**Снимок кэша**» (размер и число файлов — сверять с диалогами программы):

   ```powershell
   Get-ChildItem -Recurse -File $prog | Measure-Object -Sum Length |
     Select-Object Count, @{n='MB';e={[math]::Round($_.Sum/1MB,1)}}
   ```

4. «**Снять процесс**» (выполнять, пока клиент 1С открыт):

   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='1cv8.exe' OR Name='1cv8c.exe' OR Name='1cv8s.exe'" |
     Select-Object ProcessId, ExecutablePath, CommandLine | Format-List
   ```

5. Запуск испытуемого — из корня репозитория: `uv run onecstarter`.

Критерий «какой клиент запустился» — всегда «Снять процесс», не заголовок
окна: тонкий = `1cv8c.exe`, толстый = `1cv8.exe` (ENTERPRISE), конфигуратор =
`1cv8.exe` (DESIGNER в командной строке). Урок T-04.7: устный ответ трижды
расходился с фактами — сверяем артефактами, не словами.
