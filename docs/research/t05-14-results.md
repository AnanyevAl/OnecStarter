# T-05.14 — /N /P при запуске по /IBName

Спека v2.2, §1. Заполняет скрипт `t05-14-launch-matrix.ps1`, запускает
заказчик. Пароль в этом файле не появляется — скрипт заменяет его
на `<пароль>` и в команде, и в снимке процесса.

Тестовая база: файловая, без конфигурации, пользователь `tester`,
аутентификация 1С включена, аутентификация ОС выключена. Готовность
подтверждена: запуск из штатного стартера спрашивает логин и пароль.

Версия платформы: 8.3.27.2214 (по каталогу установки: на машине единственная
сборка 8.3.27 — `C:\Program Files\1cv8\8.3.27.2214`; запуск шёл через
`8.3.27.2214\bin\1cv8c.exe`). Дата: 2026.09.06.

Запуск B2 (`/N` и `/P` без кавычек) — запасной вариант на случай отказа
B. Это форма справочника, не дефект скрипта: она не переносит пробел
и `"` ни в логине, ни в пароле. Если логин или пароль их содержат,
B2 давать не получится — пропустите его и переходите к C/D.

| Запуск | Команда | Диалог? | Вошли как | ibases.v8i изменился? |
| --- | --- | --- | --- | --- |
| A | `ENTERPRISE /IBName"Тест пароля"  /AppAutoCheckVersion /AppAutoCheckMode` | n |  | нет |
| A | `ENTERPRISE /IBName"Тест пароля"  /AppAutoCheckVersion /AppAutoCheckMode` | y |  | нет |
| B | `ENTERPRISE /IBName"Тест пароля" /N"tester" /P"<пароль>" /AppAutoCheckVersion /AppAutoCheckMode` | n | tester | нет |
| C | `ENTERPRISE /IBName"Тест пароля" /N"tester" /P"<пароль>" /WA- /AppAutoCheckVersion /AppAutoCheckMode` | n | tester | нет |

## Вывод

Заказчик уточнил устно 06.09.2026: первая строка A (диалога нет) отброшена —
на момент этого запуска тестовая база ещё не была настроена правильно
(«неправильно настроил тестовую базу»). Валидный контроль — вторая строка A
(диалог есть).

1. `/N"tester" /P"<пароль>"` сразу после `/IBName"…"` — клиент вошёл под
   `tester` БЕЗ диалога (запуск B), тогда как контроль A (те же `/IBName`,
   без ключей учётных данных) дал диалог логина. Значит ключи `/N`/`/P`
   перекрывают запись `.v8i` при запуске по `/IBName`.
2. Форма значения — в кавычках, с удвоением внутренних, как у `/IBName`:
   B сработал с первого раза. B2 (без кавычек) не потребовался и не измерен —
   форма без кавычек остаётся **[Д]**.
3. `/WA-` не требуется: B вошёл без него без диалога; C с ним тоже вошёл без
   диалога — ключ безвреден, но не обязателен.
4. `ibases.v8i` не изменился ни в одном запуске (обе строки A, B, C) —
   платформа учётные данные из командной строки в файл не дописывает.
5. Запуск D (`/IBConnectionString`) не измерен — не потребовался, так как B
   сработал с первой попытки; остаётся неизмеренным.
